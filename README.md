# Jackpotcity Canada — Render

Статический лендинг с отдельной страницей колеса, подготовленный для публикации через Git на Render.

## Маршруты

- `/` — основная французская страница;
- `/city` — постоянный редирект на `/city/`;
- `/city/` — полноэкранное колесо.

## Деплой через Git

1. Создайте новый Git-репозиторий и загрузите в него содержимое этой папки.
2. В Render выберите **New → Blueprint**.
3. Подключите репозиторий.
4. Render прочитает `render.yaml`, выполнит `sh build-render.sh` и опубликует папку `dist`.
5. После успешного деплоя проверьте корневой URL и URL `/city/`.

Повторные push в подключённую ветку автоматически запускают новый деплой.

## Локальная сборка

```bash
sh build-render.sh
python3 -m http.server 8080 --directory dist
```

Затем откройте:

- `http://localhost:8080/`
- `http://localhost:8080/city/`

В опубликованную папку попадают только два HTML-файла и две используемые JPG-фотографии. Исходники, промты, архивы и PNG-файлы не публикуются.
